# MIRA Cinema asset record

Two transparent product derivatives were created with the built-in image tool, using the original user-supplied photos as edit targets. The gallery still uses the original photographs. The cinematic derivatives preserve the visual product concept; the refrigerator's cabinet-occluded lower-right edge was reconstructed. Native SVG silhouette clips refine the displayed edges without modifying the generated PNG alpha.

Sources: `dist/assets/fridge.jpg`, `dist/assets/brew.jpg`.
Final project assets: `dist/assets/fridge-cutout-v2.png`, `dist/assets/brew-cutout-v2.png`.
